## 2. Выбор размера рабочей ноды
Ключевые ограничения при выборе:

Самый «тяжёлый» pod — БД / Кеш: 4 ГБ RAM, 1 CPU
Stateful-сервисы (БД, Кеш) требуют PodAntiAffinity → каждая реплика на отдельной ноде → минимум 3 ноды
Нода должна вмещать 1 pod БД + 1 pod Кеша = 8 ГБ RAM, 2 CPU + что-то ещё
Выбор: нода 16 ГБ RAM / 8 CPU

Аргумент              |                  Пояснение                   |
----------------------|----------------------------------------------|
Не слишком маленькая  | Вмещает крупные stateful-поды + часть backend|
Не слишком большая    | Ограничен blast radius при отказе ноды       |
Хороший баланс CPU/RAM| 8 ядер × 1 ГБ условный коэффициент ≈ 16 ГБ   |

## 3. Системный оверхед на каждую ноду
На каждой ноде Kubernetes резервирует ресурсы для ОС, kubelet и системных pods:

Ресурс| Оверхед (kube-reserved + system-reserved)| Доступно приложениям|
------|------------------------------------------|---------------------|
ОЗУ   |    ~2 ГБ (≈ 10% + фиксированная часть)   |       14 ГБ         |
CPU   |                 ~1 ядро                  |       7 ядер        |

## 4. Минимальное количество нод (без резерва)
```
По RAM:         30.25 ГБ  ÷  14 ГБ/нода  =  2.16  →  3 ноды
По CPU:         17 ядер   ÷  7 ядер/нода  =  2.43  →  3 ноды
По Anti-affinity:  3 реплики БД + 3 реплики Кеша  →  минимум 3 ноды
```
**Минимум: 3 ноды**

### Проверка размещения на 3 нодах:

Нода  |	         Поды                       |  RAM занято     |   CPU занято  |
------|-------------------------------------|-----------------|---------------|
Node-1|	      БД-1, Кеш-1, Backend ×3       | 4+4+1.8 = 9.8 ГБ|    1+1+3 = 5  |
Node-2|	      БД-2, Кеш-2, Backend ×4       |4+4+2.4 = 10.4 ГБ|    1+1+4 = 6  |

Итого |                                     |	  30.2 ГБ        |    17      |

## 5. Резерв на отказ ноды (N+1)

Добавляем 1 ноду так, чтобы при выходе любой ноды из строя кластер смог переразместить все поды на оставшихся.

`Итого worker-нод:  3 (рабочие) + 1 (резерв) = 4 ноды`

**Проверка при потере 1 ноды (остаётся 3):**

Ресурс|	Доступно (3 ноды) | Требуется |   Результат   |
------|-------------------|-----------|---------------|
RAM   |	3 × 14 = 42 ГБ    | 30.25 ГБ  | запас 11.75 ГБ|
CPU   |	3 × 7 = 21 ядро   |  17 ядер  | запас 4 ядра  |
